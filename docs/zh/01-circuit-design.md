## 1. 系统架构

```
   ┌────────┐  USB-C(5V+数据)  ┌──────────────┐   PWM 20kHz   ┌─────────┐   OUT1/2   ┌────────┐
   │  电脑  │ ───────────────> │ ESP32-C3     │ ──1kΩ──────>  │ DRV8871 │ ─────────> │ N30    │
   │ Python │                   │ SuperMini    │               │  H 桥   │            │ 电机   │
   └────────┘                   └──────┬───────┘               └────┬────┘            └────────┘
                                       │ GPIO4                      │ VM
                                    ┌──┴───┐                   ┌────┴─────┐
                                    │面板开关│                  │ 12V 电源 │
                                    │  →GND │                   └──────────┘
                                    └───────┘
                         ESP32 GND / DRV8871 GND / 12V 负极 ── 共地
```

**分工**：ESP32 只负责"按指令输出 PWM"+"看门狗保护"，转速决策全在电脑端（CPU 占用映射到占空比）。这样调曲线不用重烧固件。

## 3. 关键设计说明

### 3.1 为什么 IN2 固定接地（单方向）

DRV8871 是 H 桥，IN1/IN2 两路输入组合决定四种状态：

| IN1 | IN2 | 输出 | 本项目 |
|---|---|---|---|
| PWM | 0 | 正转调速 | ✅ **使用的组合** |
| 0 | PWM | 反转调速 | 未用 |
| 0 | 0 | **滑行停转**（coast） | ✅ 停机时处于此态 |
| 1 | 1 | 刹车（brake） | 未用 |

IN2 接地 → 只做单方向。PWM=0 时 IN1=IN2=0 → 自然滑行，不会急刹，听感更接近真实喷气发动机的"减速滑行"。模型只需单方向，这样最简。

### 3.2 限流电阻怎么算

DRV8871 的限流阈值由 ILIM 脚对地的电阻决定：

```
I_limit ≈ 64 / R_ILIM(kΩ)   [A]
```

- R = **47 kΩ** → I_limit ≈ **1.36 A**
- 想要别的限流点：`R(kΩ) = 64 / I_limit`（例如 2A → 32 kΩ；1A → 64 kΩ）

**这个电阻不是串在电机回路里的**，是给芯片内部比较器设阈值的，1/4W 足够。

N30 常见额定电流 0.5~1.5 A，1.36 A 的限流既能保证起转冲量，又能在堵转时保护电机和驱动。

### 3.3 1 kΩ 串联电阻的作用

GPIO3 → 1 kΩ → IN1。作用：限制瞬间灌入 IN1 的电流、抑制 PWM 边沿振铃，防止 ESP32 引脚和驱动输入互相"打架"。20 kHz 下这颗电阻不会影响上升沿。

### 3.4 PWM 频率为什么选 20 kHz

- **高于人耳上限（20 kHz）** → 听不到 PWM 的"吱吱"啸叫
- 太高的频率会让 DRV8871 开关损耗上升发热
- 10 bit 分辨率（1024 级）在 20 kHz 下由 ESP32-C3 的 LEDC 外设轻松达到

对应固件常量：`PWM_FREQ = 20000`、`PWM_RES = 10`。

### 3.5 失效安全（fail-safe）设计

开关逻辑是**闭合到 GND 才允许转**（GPIO4 内部上拉，悬空=高=OFF）：

- 开关没接、线断了、开关坏了 → 一律读到"OFF" → 电机不转
- 而不是反过来（必须短接才停），那样一旦线断就会失控

固件还有第二层保护：**看门狗 2 秒**。电脑休眠/关机/拔线后，2 秒内收不到任何命令就自动滑行停转，不会出现"人走了电机一直转"。

### 3.6 电源为什么分开

- **ESP32 由 USB 供电**：电压稳定、和电脑共地、烧录方便
- **12V 只给电机**：电机启停瞬间电流冲击大，共用一个电源容易把 MCU 拉重启

但两者**必须共地**（12V 负极接 ESP32 GND），否则 PWM 信号没有共同参考电平，驱动会乱翻。

## 4. 电气参数速查

| 参数 | 值 |
|---|---|
| 逻辑电平 | 3.3 V（ESP32-C3） |
| PWM 频率 / 分辨率 | 20 kHz / 10 bit（1024 级） |
| 电机电源 VM | 12 V（DRV8871 允许 6.5~45 V） |
| 限流点 | 1.36 A（R_ILIM = 47 kΩ） |
| 峰值能力 | DRV8871 标称 3.6 A |
| 待机逻辑 | GPIO4 悬空 = OFF（不转） |
| 通信断线保护 | 2 秒无命令 → 滑行停转 |
