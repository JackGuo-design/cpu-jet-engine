# 三、接线与安装说明

> 中文原版。英文版见 [`docs/en/02-assembly.md`](../en/02-assembly.md)。本文档采用 CC BY-SA 4.0 授权，见 [`LICENSE-docs`](../../LICENSE-docs)。

**前置条件**：机身（CATIAV5FTW，MakerWorld 744985）与打印动力组件（炒面大师，
MakerWorld 中国站 1455937）已按各自说明书装配完成，署名与许可证条款见
[`CREDITS.md`](../../CREDITS.md)。本文只讲电子部分。

配合 [`../assets/wiring-diagram.zh-CN.png`](../assets/wiring-diagram.zh-CN.png) 一起看。**顺序很重要：先信号，再地，最后才上 12V 和电机。**

## 1. 引脚对照表

### ESP32-C3 SuperMini 侧

| 板上丝印 | 接到 | 说明 |
|---|---|---|
| `GPIO3`（部分板印 `3`） | → 1 kΩ → DRV8871 `IN1` | 20 kHz PWM 输出 |
| `GPIO4`（印 `4`） | → 开关一端 | 内部上拉，开关另一端接 GND |
| `GND` | → 公共地 | 必须与 12V 负极相连 |
| `5V` / `VBUS` | 不接 | 由 USB-C 直接供电 |
| `GPIO8` | 不接 | 板载 LED，固件内部用（低电平点亮） |

> ⚠️ 不同厂家的 SuperMini 丝印略有差异，**接之前用万用表或固件的 `P` 命令确认引脚**（发 `P` 会打印 9 个候选 GPIO 的实时电平）。

### DRV8871 模块侧

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| `VM` | 12V 正极 | 电机电源，**绝不接 ESP32** |
| `GND` | 公共地 | 与 ESP32 GND、12V 负极同一条 |
| `IN1` | ← 1 kΩ ← GPIO3 | PWM 输入 |
| `IN2` | GND | 固定低电平 = 单方向 |
| `ILIM` | 47 kΩ → GND | 设定限流 1.36 A |
| `OUT1` | 电机一端 | 方向不对就与 OUT2 对调 |
| `OUT2` | 电机另一端 | |

> 有些 DRV8871 模块的 ILIM 电阻已经焊在板上（常见 30k/47k）。**如果模块自带，就不用外接**，先看一下板子上那个电阻的丝印值。

## 2. 接线步骤（按顺序）

**第 1 步：信号线（不上电）**
1. GPIO3 → 1 kΩ → DRV8871 `IN1`
2. GPIO4 → 开关一端
3. DRV8871 `IN2` → 公共地
4. DRV8871 `ILIM` → 47 kΩ → 公共地（若模块自带则跳过）

**第 2 步：地线（关键，别漏）**
5. ESP32 `GND` → 公共地
6. DRV8871 `GND` → 公共地
7. 开关另一端 → 公共地

> 建议用端子排或把三根地线拧在一起焊牢。**不要只用面包板的细弹簧片过 1 A 以上电流。**

**第 3 步：去耦电容**
8. 100 µF 电解（注意极性！正极朝 VM）+ 0.1 µF 陶瓷，并联在 DRV8871 的 `VM` 与 `GND` 之间，尽量靠近芯片

**第 4 步：电机**
9. 电机两根线接 `OUT1` / `OUT2`（此时先不上 12V）

**第 5 步：电源**
10. 12V 正极 → DRV8871 `VM`
11. 12V 负极 → 公共地

## 3. 上电自检（务必按这个流程，别一上来就插电机）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| ① | 只插 USB，**不接 12V、不接电机** | 电脑出现串口设备（Windows: 设备管理器 → 端口；Linux: `/dev/ttyACM0`） |
| ② | 打开串口（115200） | 能看到启动信息：`# jetengine-usb ... ESP32-C3 SuperMini + DRV8871` |
| ③ | 发 `V` | 回一行版本与参数：`# jetengine-usb 1.1 pwm=GPIO3 20kHz idle=80% kick=45% max=100% wd=2000ms` |
| ④ | 发 `P` | 回 9 个 GPIO 电平，用来确认开关到底接在哪个脚 |
| ⑤ | 拨动开关，发 `P` 或 `?` | 接 GND 的那一脚在 0/1 之间变化 |
| ⑥ | 接上 12V（仍不接电机），万用表量 `OUT1`-`OUT2` | 发 `T 50` 后应有约 12V×50% ≈ 6V 的直流电压 |
| ⑦ | 断电，接上电机，再上电 | 闭合开关 → 电机起转；断开 → 滑行停转 |

> 第 ⑥ 步是分离"驱动有没有输出"和"电机能不能转"的关键。如果这里没电压，问题在驱动/接线，不在电机。

## 4. 开箱测试命令（串口里直接敲，`\n` 结尾）

| 命令 | 作用 |
|---|---|
| `T 30` | 目标 30% 转速（同时也是心跳，2 秒不发就自动停） |
| `T 0` 或 `S` | 停机（滑行） |
| `T 100` | 满速 |
| `?` | 立刻回报一行状态 |
| `V` | 版本与参数 |
| `P` | 引脚自检 |
| `E 1` | **绕过面板开关**强制允许转（调试电机通路用；断电自动复位为 0） |
| `K` | 清故障 |

> 排查时很好用：`E 1` + `T 50` 可以完全排除开关问题，直接验证电机通路。

## 5. 常见故障对照

| 现象 | 最可能的原因 |
|---|---|
| 串口里没有设备 | 烧固件时没带 `CDCOnBoot=cdc`；或用了只能充电的 USB 线 |
| 有串口但发命令没反应 | 波特率不是 115200；或 `\r\n` 都发了但固件只认 `\n`（一般没问题） |
| `P` 显示 GPIO4 一直是 0 | 开关接成了"常闭"，或线搭到了 GND（固件认为开关一直闭合 = 一直允许转） |
| 发 `T` 后 `R` 回报的 target 比发的值大 | 发的是低速值，被固件 `DUTY_MIN_RUN` 抬到了下限（本版 15%，正常不会） |
| 电机只抖不转 | 占空比低于这台电机的静摩擦门槛 → 提高目标值，或按 [04-host-software.md](04-host-software.md) 重新标定 `DUTY_MIN_RUN` |
| 转一下就停 | 主机没持续发命令（心跳断了）→ 检查 `engine_host.py` 是否在跑 |
| 电机转但 2 秒后自己停 | 同上，看门狗超时。主机端 `sample_interval` 应 ≤ 1.0 秒 |
| 驱动发烫、电机没劲 | 限流设太低（ILIM 电阻太大）；或电源带不动（1 A 适配器正常运转够用，堵转时会被拉低） |
| 电机嗡嗡响但不转，且 12V 电压塌陷 | 正常现象。DRV8871 限流 1.36A，而参考用的适配器只有 1A，堵转时会把电源拉低 —— 适配器自身限流保护，不会烧东西，但电压塌陷会让万用表读数看起来不对。排除卡阻即可；需要做堵转试验就换更大电流的电源 |
| ESP32 反复重启 | 12V 干扰窜入 5V，或没共地；检查去耦电容与走线 |
